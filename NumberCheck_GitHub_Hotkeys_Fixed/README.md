# Number Check — ตรวจเลขบัตรประชาชนจากภาพบนหน้าจอ

โปรแกรมเดสก์ท็อปสำหรับ Windows 10/11 เปรียบเทียบ **เลขบัตรประชาชน 13 หลักที่คัดลอก** กับเลขที่ OCR อ่านได้จากภาพบัตร สามารถครอบภาพทั้งใบ อ่านภาพหมุน 0°/90°/180°/270° และทำงานกับจอที่สองได้ตามความสามารถของ Windows ที่ใช้

**สถานะ:** โปรเจกต์ต้นแบบ ยังไม่ได้ผ่านการทดสอบบน Windows ทุกเครื่อง / ไม่ใช่ระบบยืนยันตัวบุคคลจริง โปรแกรมไม่ควรตัดสินเอกสารจริง-ปลอม และผล OCR อาจผิดพลาด

## ดาวน์โหลด EXE จาก GitHub โดยไม่ต้องสร้างเอง

1. เปิด repo บน GitHub แล้วเลือกแท็บ **Actions**
2. กด **Build Windows Portable** ทางซ้าย แล้ว **Run workflow** → **Run workflow** (ในสาขา `main`)
3. รอเครื่องหมาย ✓ สีเขียว จากนั้นคลิกงานล่าสุด
4. เลื่อนลงไปที่ **Artifacts** → **NumberCheck-Windows-Portable** เพื่อดาวน์โหลด
5. แตกไฟล์ ZIP ที่ดาวน์โหลด อาจมี ZIP ซ้อน 1 ชั้น แล้วคัดลอก **ทั้งโฟลเดอร์ NumberCheck** ไปยังแฟลชไดรฟ์
6. เปิด `NumberCheck.exe` ภายในโฟลเดอร์บน Windows โดยไม่ต้องติดตั้ง Python/Tesseract เพิ่ม

การสร้างครั้งแรกอาจใช้หลายนาที และอาจล้มเหลวหากแพ็กเกจ Tesseract ของ Chocolatey เปลี่ยนตำแหน่งติดตั้ง สามารถดูสาเหตุใน Actions logs; ยังไม่มีการรับรองว่าการสร้างจะผ่านจนกว่าจะรันจริงบน GitHub

## วิธีอัปโหลดโปรเจกต์ขึ้น GitHub ผ่านเว็บ

1. ไปที่ https://github.com/new และสร้าง repository (แนะนำ **Private** ก่อนทดลอง)
2. **อย่า** เลือกสร้าง README/.gitignore อัตโนมัติ
3. เปิด repository → **uploading an existing file**
4. อัปโหลด **ไฟล์และโฟลเดอร์ที่อยู่ภายใน** โฟลเดอร์ NumberCheck_GitHub ไม่ใช่ไฟล์ ZIP ทั้งก้อน ต้องแน่ใจว่า `.github/workflows/build-windows.yml` ถูกอัปโหลดด้วย (บาง browser ซ่อนไฟล์/โฟลเดอร์ที่ขึ้นต้นด้วยจุด)
5. กด **Commit changes** แล้วไปที่ **Actions** เพื่อสร้าง EXE

**วิธีที่เชื่อถือได้กว่า** คือใช้ GitHub Desktop: `File → Add local repository` หรือ `Create a New Repository from Local Folder` แล้ว Publish repository (รวมโฟลเดอร์ `.github`)

## วิธีใช้

คัดลอกเลข 13 หลักด้วย `Ctrl+C` → แสดงภาพบัตร → กด `F8` หรือ `Ctrl+Alt+Q` → ลากครอบทั้งบัตร → ตรวจเลขทั้งสองฝั่งและสีสถานะในหน้าต่าง (ดู `README_FOR_STAFF_TH.txt`)

**สีส้มไม่ได้แปลว่าเลขผิด** แปลว่า OCR ยังยืนยันไม่ได้ แม้ตัวเลขที่แสดงจะดูตรงกัน เพราะระบบตรวจผลด้วยหลายรอบและหลักตรวจสอบ หากตัวเลขต้นฉบับไม่ผ่าน checksum ควรตรวจซ้ำด้วยคน

## การพัฒนาใน Windows

ต้องมี Python 3.12 และ Tesseract OCR (ข้อมูลภาษา `eng`)

```powershell
python -m pip install -r requirements-build.txt
python -m pytest -q
python number_check.py
```

## ความปลอดภัย / ความเป็นส่วนตัว

- อย่านำรูปบัตรประชาชนหรือข้อมูลส่วนบุคคลจริงใส่ใน GitHub repository / Issue / Actions logs
- โค้ดทำ OCR ภายในเครื่อง แต่ภาพบนหน้าจออาจมีข้อมูลอ่อนไหว; ระวังภาพหน้าจอและการเข้าถึงเครื่อง
- Windows SmartScreen อาจแจ้งเตือน EXE ที่ยังไม่ได้เซ็นชื่อ; ให้ฝ่าย IT ตรวจสอบก่อนอนุญาต
- GitHub Actions ใช้สร้างโปรแกรมเท่านั้น ไม่ต้องอัปโหลดรูปบัตรใด ๆ
- สถานะการจับคู่เป็นเพียงเครื่องมือช่วยตรวจ ไม่ใช่หลักฐานว่าบัตรถูกต้องทางกฎหมาย

## โครงสร้าง

- `number_check.py` — โปรแกรมหลัก (GUI + OCR)
- `.github/workflows/build-windows.yml` — สร้าง EXE/ZIP บนเครื่อง Windows ของ GitHub
- `requirements*.txt` — ไลบรารี
- `tests/` — ทดสอบฟังก์ชันตรวจเลข
- `README_FOR_STAFF_TH.txt` — คู่มือพนักงาน

เครื่องมืออ้างอิง: Python, Pillow, pytesseract, PyInstaller และ Tesseract OCR โปรดตรวจสอบเงื่อนไขใบอนุญาตของส่วนประกอบก่อนแจกจ่าย

## คีย์ลัดในรุ่นนี้

โปรแกรมใช้ Windows API `RegisterHotKey` โดยตรงสำหรับ **Ctrl + Alt + Q** และ **F8** ทั้งสองปุ่มทำงานแม้หน้าต่าง Number Check ไม่ได้เป็นหน้าต่างที่เลือกอยู่ ตราบใดที่โปรแกรมยังเปิดอยู่ในเซสชัน Windows เดียวกัน หากปุ่มใดถูกแอปอื่นแย่งใช้ จะมีหน้าต่างแจ้งเตือนชื่อปุ่มนั้นทันที ไม่เงียบเหมือนรุ่นก่อน

> ข้อจำกัด: คีย์ลัดไม่ทำงานบนหน้าจอล็อก/UAC secure desktop และอาจใช้ไม่ได้เมื่อแอปอื่นจองปุ่มไว้ก่อน หรือระหว่างเซสชัน Remote Desktop บางรูปแบบ; ให้ลองปิดแอปที่จองปุ่มก่อน
