NUMBER CHECK - คู่มือพนักงาน (Windows 10/11)

1) เปิด NumberCheck.exe ในโฟลเดอร์นี้ (ห้ามย้าย EXE ออกไปเดี่ยว ๆ)
2) ในระบบงาน ให้คัดลอกเลขบัตรประชาชน 13 หลักด้วย Ctrl+C
3) เปิดภาพบัตรบนจอที่ 1 หรือ 2
4) กด F8 แล้วลากครอบภาพบัตรทั้งใบ จากนั้นปล่อยเมาส์
5) ดูเลขที่โปรแกรมอ่านได้และผลเปรียบเทียบ

สีเขียว: พบเลขที่ OCR ยืนยันได้ระดับหนึ่งและตรงกับเลขที่คัดลอก
สีแดง: พบเลขที่ OCR ยืนยันได้ระดับหนึ่งแต่ไม่ตรง
สีส้ม: ไม่สามารถยืนยันเลขที่อ่านได้ ต้องตรวจด้วยสายตา

รองรับการหมุน 0 / 90 / 180 / 270 องศา
ถ้าปุ่ม F8 ถูกโปรแกรมอื่นใช้งาน ให้คลิกปุ่มเลือกภาพในโปรแกรม
ข้อมูล OCR ประมวลผลบนเครื่อง ไม่ต้องอัปโหลดภาพบัตร
คำเตือน: ไม่ใช่ระบบยืนยันว่าบัตรจริงหรือเป็นของบุคคลนั้น และ OCR อาจอ่านผิด
ควรให้เจ้าหน้าที่ตรวจภาพต้นฉบับในกรณีสำคัญ
หาก Windows แจ้งเตือนความปลอดภัย ให้หน่วย IT ตรวจสอบไฟล์ก่อนใช้

คีย์ลัดทั้ง F8 และ Ctrl+Alt+Q ทำงานใน Windows แม้กำลังเปิด Chrome อยู่ แต่ต้องเปิด NumberCheck.exe ค้างไว้ก่อน หากปุ่มไม่พร้อมใช้งานจะมีแจ้งเตือนตอนเปิดโปรแกรม
